Автоматизированный комплекс поиска аномалий в данных учета дорожного движения (А-134)


ОПИСАНИЕ ПРОЕКТА
Проект представляет собой блок большего проекта и  предназначен для пакетного автоматического анализа почасовых данных интенсивности и состава транспортных потоков на участке А-134 (подъезд к г. Воронеж).

Главная цель - объективный математический аудит и выявление аномальных суток и месяцев без субъективных предположений о причинах инцидентов.

Комплекс выполняет:
- Анализ сложных Excel-файлов с почасовой гранулярностью;
- Поиск дорожных заторов, аварийных спадов, всплесков и технических сбоев датчиков;
- Сравнение суточных профилей движения с типичными ритмами рабочих и выходных дней;
- Межгодовой макро-анализ месяцев (Year-over-Year, YoY);
- Автоматическую генерацию цветного Excel-реестра и графиков сравнения.

АРХИТЕКТУРА ДЕТЕКЦИИ (3 СИСТЕМЫ ПОИСКА АНОМАЛИЙ)
Алгоритм объединяет три независимые математические системы, исключающие взаимные «слепые зоны»:

СИСТЕМА 1: Физическая целостность и телематика (Rule-based)
- Залипание датчика (Flatline): фиксация одинаковых значений интенсивности на протяжении 3+ часов подряд;
- Экстремальные заторы: падение скорости < 65 км/ч при загрузке полосы > 15%;
- Нулевая скорость при потоке: сбой телематики (0 км/ч при интенсивности > 50 авт./ч);
- Неполные сутки: учет и фиксация дней, где записано менее 24 часов.

СИСТЕМА 2: Форма суточного профиля и часовая динамика (Pattern / Correlation-based)
- Анализ суточного ритма: сравнение фактического 24-часового вектора с медианным профилем месяца для данного типа дня (будни/выходные);
- Коэффициент корреляции Пирсона: если r < 0.75 при достаточном объеме трафика, день маркируется как аномальный;
- Часовые провалы/всплески: резкие отклонения по легковым автомобилям (> 40% от нормы часа).

СИСТЕМА 3: Амплитудная статистика и макро-анализ (Statistical / Distribution)
- Суточный уровень: Modified Z-score на основе робастных метрик (медиана и MAD). Фиксация спадов и всплесков суточного объема (отклонения от нормы на 25-50%+);
- Месячный уровень (YoY): сопоставление одинаковых месяцев разных лет. Выявление долгосрочных ремонтов (падение скорости > 15 км/ч), структурных сдвигов грузового каркаса (изменение доли грузовиков > 8%) и аномалий среднемесячной суточной интенсивности (ССИ/MADT > 25%).

ТРЕБОВАНИЯ И УСТАНОВКА
Python 3.8 или новее.
Необходимые внешние библиотеки: pandas, openpyxl, matplotlib, numpy.
Установка зависимостей одной командой: 
$ pip install pandas openpyxl matplotlib numpy

ИНСТРУКЦИЯ ПО РАБОТЕ
1. Поместите ваши файлы выгрузок (.xlsx или .xls) в папку input_data/. (Скрипт поддерживает работу как с одним тестовым файлом, так и с пакетом из 70+ файлов за весь период).
2. Убедитесь, что файлы закрыты и сохранены в программе Microsoft Excel.
3. Запустите скрипт: 
$ python analyzer_a134.py

Дополнительные флаги (опционально): 
--input Путь к пользовательской папке с исходными данными (по умолчанию: ./input_data)
--output Путь к папке для сохранения отчетов (по умолчанию: ./reports)

СПЕЦИФИКАЦИЯ ВХОДНЫХ ДАННЫХ
Файлы Excel имеют вертикальную структуру на одном рабочем листе:
- Строки заголовков, пустые разделители и служебные хвосты («Итого», «Среднее», «%») отсекаются парсером автоматически;
- Фиксация данных происходит строго по наличию корректного таймстемпа в первой колонке;
- Таблица состоит из 29 колонок: Дата/Время, Общая интенсивность (Итого/Прямое/Обратное), Категории ТС (Легковые, Малые груз., Грузовые, Груз. большие, Автопоезда, Автобусы, Мотоциклы), Скорость (Прямое/Обратное), Загрузка (Прямое/Обратное).

ВЫХОДНЫЕ ДАННЫЕ И РЕЗУЛЬТАТЫ
По завершении работы формируются два типа артефактов:

1. Реестр traffic_anomalies_report.xlsx:
- Лист «Аномальные сутки»: детальный список выявленных инцидентов (Участок, Дата, Уровень, Детектор, Факт, Норма, Отклонение %, Описание);
- Лист «Аномальные месяцы (YoY)»: список периодов с макро-отклонениями интенсивности, скорости и состава потока;
- Цветовая дифференциация: оранжевый цвет — критические сбои, светло-желтый — умеренные аномалии.

2. Графики в папке reports/plots/: 
Для каждого подозрительного дня формируется 2-панельное изображение:
- Верхняя панель: серые столбцы (медианная норма часа) в сравнении с фактической кривой аномального дня + маркер пика расхождения;
- Нижняя панель: фактическая скорость направления относительно нормы и критической границы затора.

ВАЖНЫЕ ОСОБЕННСТИ И ПРЕДОТВРАЩЕНИЕ СБОЕВ
- Блокировка файлов (Windows): если файл открыт в Excel во время выполнения, скрипт не сможет его прочитать. Закрывайте таблицы перед запуском.
- Работа с 1 файлом: при обработке только одного месяца анализ суток выполняется полностью. На листе межгодового анализа будет выведено сообщение о необходимости минимум двух лет для сравнения YoY.
- Устойчивость к поврежденным файлам: при обнаружении битого архива скрипт выводит предупреждение в консоль, пропускает проблемный файл и продолжает обработку.
- Очистка строковых чисел: парсер автоматически удаляет неразрывные пробелы (\xa0) и заменяет запятые на точки при преобразовании в числа.
