Вот контракт для вашего аналитического модуля, оформленный строго в вашем минималистичном, текстово-табличном стиле.
Поскольку исходный скрипт является консольной утилита, контракт разделен на две части: HTTP REST API (для интеграции фронтенда с веб-сервером бэкенда) и Внутренние функции (сигнатуры и логика ключевых функций самого скрипта, если фронтенд обращается к ним напрямую через RPC/Worker).

parse_traffic_excel(filepath)
Потоковый парсер для файла А-134. Находит участок трассы, распознает даты, очищает текстовые аномалии и преобразует данные в числовой формат.
Сигнатура
python
def parse_traffic_excel(filepath: str) -> pd.DataFrame
Используйте код с осторожностью.
Параметры
Параметр	Тип	Обязательный	Описание
filepath	str	да	Абсолютный или относительный путь к файлу Excel на диске
Возвращает
Поле DataFrame	Тип	Описание
road_section	string	Распознанное название или километр участка дороги
timestamp	datetime64	Дата и час замера
vol_total / _direct / _reverse	int / float	Общая интенсивность, по прямому и обратному направлению
cars_... / small_trucks_... / med_trucks_... / large_trucks_... / road_trains_... / buses_... / motos_...	int / float	Разделение интенсивности по типам транспортных средств
speed_direct / _reverse	float	Средняя скорость движения по направлениям (км/ч)
load_direct / _reverse	float	Уровень загрузки дороги по направлениям (%)
Исключения
Исключение	Условие
FileNotFoundError	Указанный файл отсутствует по заданному пути filepath
zipfile.BadZipFile	Файл поврежден и не может быть открыт библиотекой openpyxl
 
detect_daily_anomalies(df)
Поиск аномалий на суточном уровне (неполные сутки, flatline датчика, дисбаланс направлений, заторы, искажение профиля и амплитудные всплески/спады).

Параметры
Параметр	Тип	Обязательный	Описание
df	pd.DataFrame	да	Очищенный датафрейм, полученный из функции parse_traffic_excel
Возвращает
Поле DataFrame	Тип	Описание
